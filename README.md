# BMI Calculator

A React app that calculates Body Mass Index from weight (kg) and height (m) and shows the weight category.

**Live demo: https://vasu-midde.github.io/BMI_calculator/**

## Features

- Enter weight in kg and height in metres
- Calculates BMI = weight / height²
- Shows the BMI category
- Reload button to reset the form

## Run locally

```bash
npm install
npm start
```

## Deploy

```bash
npm run deploy   # builds and publishes to GitHub Pages
```

## Tech

React 18 (useState hook) · Bootstrap 5 · JavaScript · CSS
